## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/mohitpachauri0095/Java-Question.git
```

### 2. Open the Project

```bash
cd Java-Question
```

### 3. Compile the Java Program

```bash
javac first.java
```

### 4. Run the Program

```bash
java first
```
